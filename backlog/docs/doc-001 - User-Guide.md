# User Guide – SILENT SENTINEL

## Overview

SILENT SENTINEL is a tactical intelligence analysis platform that runs entirely in the browser. It provides a responsive application shell for navigating between intelligence analysis modules and accessing operational data.

## Getting Started

### Opening the Application

1. Open a supported browser (Chrome, Edge, or Firefox).
2. Navigate to the application URL or open the installed PWA.
3. The application loads with the Marine theme and displays the main dashboard.

### Application Layout

The application shell consists of four main areas:

- **Header**: Contains the application title, primary navigation modules, and global controls.
- **Sidebar**: A 64-pixel-wide vertical navigation bar on the left with icon and label pairs for intelligence disciplines.
- **Main Content**: A three-section layout with a left panel, center visualization area, and right panel.
- **Status Bar**: A footer bar displaying system status information.

## Navigation

### Keyboard Navigation

All interactive elements support keyboard navigation:

- Press **Tab** to move focus between header and sidebar controls.
- Press **Enter** or **Space** to activate a focused button.
- Focus states are visible with an accent border or outline.
